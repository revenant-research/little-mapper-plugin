# Little Mapper

Little Mapper gives work a shared memory across the AI assistants people already use. What you start in one assistant, you or a colleague can pick up in any other, with the open questions, decisions and approvals still attached to the work. It is free to use.

## Use it

Connect Little Mapper when your assistant asks, and sign in with your work email. Then talk about work as you normally would: "What needs me?", "Remind me to send Globex the invoice on Friday", "Hand this to Kim with a note", "Ask Sam to decide on the venue", "Start a project for the Globex onboarding", "What is the status of Globex?", "Remember how we did this", "Never delete anything in Stripe". The skill in this plugin tells the assistant when to orient, when to record, and how to check your company's rules before acting in another app.

## Data

The plugin sends what you ask Little Mapper to record (work, to-dos, messages, decisions, project and map text, and reported actions in other apps) to your Little Mapper account at littlemapper.com. It stores nothing itself, and Little Mapper watches no other tool: it holds only what is submitted to it. Privacy policy: https://littlemapper.com/privacy and support: https://littlemapper.com/support

## Install in Claude Code without the directory

```
claude plugin marketplace add revenant-research/little-mapper-plugin
claude plugin install little-mapper@little-mapper
```
